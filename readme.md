# Site do Seminário

Site mobile-first para estudantes do seminário.

## Estrutura
- index.html — Página principal com todas as 9 seções
- style.css — Estilos (mobile-first, tema indigo)
- app.js — Navegação e dados de demonstração
- avatars/ — Pasta com 6 imagens de avatares do Velho Testamento

## Como usar localmente
1. Crie uma pasta chamada "seminario"
2. Salve os 4 arquivos dentro da pasta
3. Crie uma subpasta "avatars" e coloque as 6 imagens (moises.png, davi.png, ester.png, rute.png, jose.png, rebeca.png)
4. Abra index.html no navegador

## Como publicar no GitHub
1. Crie uma conta em github.com (se não tiver)
2. Crie um novo repositório chamado "seminario"
3. Faça upload de todos os arquivos E da pasta avatars
4. Vá em Settings > Pages > Source: main branch<br/>
5. Seu site estará em: https://SEU-USUARIO.github.io/seminario/

## Personalização
- Cores: edite as variáveis CSS no topo do style.css<br/>
- Dados: edite os objetos no início do app.js<br/>
- Textos: edite diretamente no index.html
